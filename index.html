Privacidad

Los archivos se procesan localmente en este navegador. La aplicación no recoge estadísticas de uso ni envía archivos o datos a terceros.

Importar documento LaTeX

Pega un documento LaTeX completo. Se convertirá a Markdown y reemplazará el contenido actual.

Almacenamiento

Lo que EdiMarkdown guarda en este navegador: el texto de las pestañas abiertas y las imágenes de sus documentos. Nada de esto sale del equipo.

Insertar cita bibliográfica

Selecciona una o varias referencias. Se insertarán con la sintaxis Markdown de Pandoc.

La cita narrativa y la de solo año requieren una única referencia.

Disponible al seleccionar una sola referencia.

Todavía no hay ninguna bibliografía cargada.

Opciones generales de los documentos

Valores de partida para todos los documentos. Cada documento puede sustituirlos por opciones propias que se guardan con él.

Idioma y autor

Marca el idioma en los cinco formatos: corrector ortográfico en DOCX y ODT, partición de palabras en LaTeX y atributo de idioma en HTML y EPUB.

Se guarda en las propiedades del archivo y aparece en el EPUB y en la portada del LaTeX. En DOCX y ODT también se escribe una línea con el nombre al principio del documento. Déjalo vacío para no incluir autor.

Índice y numeración
Bibliografía

Carga una biblioteca BibTeX (.bib) o CSL JSON. Al guardar, viajará como nombre-del-documento/references.bib y se declarará en el Markdown.

Ninguna bibliografía cargada.

Nueva referencia

Amplía la biblioteca cargada o crea una nueva. Separa varios autores con punto y coma.

Si la dejas vacía, se generará una automáticamente

Si queda vacío se usa «Referencias».

Estilo de citas

APA 7 es el estilo predeterminado. Puedes elegir otro estilo incluido o cargar un archivo CSL propio.

Ningún archivo CSL cargado.

La bibliografía se guarda junto al documento para que sea portable. El CSL personalizado permanece en este dispositivo. Nada se envía a ningún servicio.

Portada del EPUB

Es la imagen que se ve en la estantería del lector de libros. Solo afecta al EPUB.

Solo para LaTeX

Se aplica al exportar a TEX y al copiar LaTeX como documento completo.

Se inserta tal cual al final del preámbulo. Si contiene errores, el documento fallará al compilar.

Opciones de este documento

Se guardan con el documento. Lo que dejes en «Heredado» usa el valor general que se muestra debajo.

Un perfil guarda el texto, la página y el índice para reutilizarlos en otro documento. Aplicarlo solo rellena los campos: nada cambia hasta que pulses «Aplicar».
